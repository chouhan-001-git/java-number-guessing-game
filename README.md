# Number Guessing Game

A simple console-based Number Guessing Game built using Java.

## Features
- Generates a random number between 1 and 100
- Provides hints when the guess is too high or too low
- Counts valid attempts
- Handles invalid input
- Uses loops and conditional statements

## Technologies Used
- Java
- IntelliJ IDEA
- Git and GitHub

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Ensure a compatible JDK is configured.
4. Run the Java main class.

## Concepts Practiced
- Variables and data types
- Scanner and Random
- While loops
- If-else statements
- Input validation
- Git version control
